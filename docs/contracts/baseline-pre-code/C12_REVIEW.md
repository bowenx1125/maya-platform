# C12 用户最终总确认材料

状态：`2026-08-28 MANUAL-ACCEPTANCE DELTA .6 FROZEN / SOL HIGH G0-S PASS / G1 AUTHORIZED`；其余 C12 继续冻结
目的：用非技术语言确认“我们将要做的网站”与最终验收边界

## 1. 最终要做什么

这是一个课堂文明互鉴教学网站：

1. 学生以小组身份制作文化 Agent；
2. 每个 Agent 有学生自己写的 `AGENT.md`、明确启用的 Markdown RAG、3D 头脸和可选自定义音色；
3. 学生发布不可修改的版本；
4. 教师查看所有小组已发布成果，选择 2-5 个 Agent；
5. 网站按 A-E 顺序确定性生成两轮英文文明辩论计划；课堂开始只展示第一位，每回合结束后由教师点击“下一步”才展示下一位；
6. 辩论结束后教师打开二维码，观众独立投票和发弹幕；
7. 大屏显示全部原始“昵称 + 弹幕”和匿名票数；
8. 后台去昵称、聚类和筛选弹幕；
9. Maya 根据真实辩论、实际引用证据、票数和匿名课堂洞察生成英文文明互鉴报告。

## 2. 学生端

- 一个小组可以创建多个 Agent。
- 一个小组有共享 Markdown 资料库，但每个 Agent 只读自己明确启用的文件。
- 其他小组完全看不到本组 Agent、MD、RAG 和音色。
- 学生自由编写 `AGENT.md`，不强制栏目，最多 12,000 字符。
- 每个 Agent 草稿启用的 RAG Markdown 合计最多 100,000 字符。
- 真正使用向量检索；无命中时诚实显示一般推理和空来源。
- 已发布版本不能修改；学生创建下一版本、继续编辑唯一草稿、发布更新。
- 新版发布后，教师不能再为新辩论选择旧版；历史辩论仍固定旧版。
- Agent 可以归档/取消归档；历史不删除。
- 自定义音色不是发布必需；没有或删除后使用兜底音色。
- Demo 学生端不看课堂控制、辩论历史、Maya 报告或测试译文。

## 3. 教师端

- 只读查看两个小组全部已发布历史版本的冻结内容。
- 永远看不到学生未发布草稿或未被发布版本使用的组内 MD。
- 创建辩论时按点击顺序自动分配 A-E，界面使用 `A. Bowen Agent` 格式。
- 只能选择未归档 Agent 的当前发布版。
- 固定两轮，不提供轮数、总时长或单回合时长输入，只显示预计时长。
- 每个 Agent 可以指定支持/反对/中立，也可以开放阐述。
- Maya 固定存在，不提供关闭开关。
- 教师独占启动、暂停、继续、跳过、停止、重播、翻译、互动开关和报告重生。

## 4. 两轮辩论

- 第一轮：表达观点并使用自己的 RAG 证据；不强制反驳或提问。
- 第二轮：结合此前全部发言和自己的 RAG，回应/反驳具体观点、提出问题、更新观点并文明说服。
- 第二轮最后一位向全班提出反思问题。
- 每回合英文 80-200 词，目标 160-185 词。
- 每次都真实检索；有来源显示文件名，无命中不能伪造证据。
- 好的 Prompt/RAG 应自然比弱输入表现好；平台不能暗中替学生补人设或证据。
- 后台最多提前准备下一位，文字和语音未到正式播放时不得泄漏。

## 5. 大屏、3D 和语音

- 大屏采用 OpenMAIC 式课堂视觉语言，但组件和代码独立实现。
- 中央显示 2-5 个头脸；内部状态仍为发言者 speaking、其他人 listening+attentive，但大屏不显示这些状态文字，只用高亮、波形、表情和动作表达。
- 同时公开完整英文气泡、RAG 状态、来源文件、平台音频和 3D 发言状态。
- 教师点击开始只公开并播放第一位；每位自然结束或 Skip 后停在等待状态，只有教师点击“下一步”才公开并播放下一位。后台可以隐藏准备下一位，但不得提前显示正文、来源、音频地址或 speaking 状态。
- Pause 可恢复；Stop 立即且不可恢复；Skip 只跳过当前剩余播放、不删除内容，并与自然结束一样等待教师下一步。
- 重播不重新调用模型或 TTS。
- 每课程只保留最近一次已启动辩论语音，直到下一场启动。
- 启动下一场前必须确认；失败时旧音频可恢复。
- Demo 只做头脸/头肩和受限参数；不做身体、高精度口型或 Lincoln 拟真开口。

## 6. 音色

- 学生本地上传一段本人 10-20 秒清晰英文音频。
- 课前注册一次音色 ID；课堂每次发言只调用 TTS，不重复克隆。
- 原始和中间声音文件在请求成功、失败或超时后都删除。
- 音色 ID 归小组复用；每个 AgentVersion 最多绑定一个。
- 删除正在使用的自定义音色后，历史 ID 仍保留，运行时自动使用兜底。
- 真实百炼 Key 已在本机安全配置；既有系统音色已注册但尚未通过 TTS。当前只授权一次无 enrollment、无自动重试的真实短英文 TTS 诊断；只有音频技术检查和平台同源试听全部成功，才激活内部兜底 VoiceProfile ID。
- 不得私自用浏览器音色、无声、1秒 Mock 提示音或文字模式冒充真实语音成功；单次诊断通过也不等于四回合真实课堂 TTS 已通过。

## 7. 课堂互动与 Maya

- 全部发言结束后不会自动开放；教师手动打开二维码。
- 手机端免登录，先填昵称，再出现独立投票和弹幕区域。
- 投票不保存昵称；弹幕保存昵称；二者没有共同记录或关联。
- 当前页面每项成功后只锁定该项；刷新可以重新提交。
- 大屏逐条显示全部成功提交的原始昵称和弹幕，不审核、不删改。
- 教师结束收集后不可重开。
- 后台去昵称、聚类相近观点、筛除无关/无实际语义内容；少数或批评意见不能因不受欢迎被筛除。
- 数量由后端按真实消息 ID 计算，不能让模型编数字。
- Maya 不读原始弹幕或昵称，不读完整 Agent RAG，只读本场实际使用证据。
- Maya 输出 600-900 词英文报告，不宣布赢家，不把多数票当作事实。
- 报告失败不破坏辩论/互动；重生创建新修订，失败不能隐藏旧成功报告。
- 零投票、零弹幕也能报告，并说明“本场无课堂互动数据”。

## 8. 账号、权限和数据

- 1 名教师、6 名学生、1 门课程、2 个三人小组为固定 Demo 数据。
- 课程/小组成员只读，不做创建、加入、邀请和角色管理。
- 同组学生内容权限相同，使用 revision 防止轮流保存互相覆盖。
- 跨组读取/下载/绑定/发布均在后端返回 404。
- 教师看发布内容，不代替学生编辑。
- 观众不是学生制作账号。
- 所有文字、来源、原始弹幕、票数和报告长期保留；音频只有最近一场。
- 前端永远不知道模型、向量库、音色供应商、外部 ID 或 API Key。

## 9. 中英文

- 网页静态界面支持中文/英文切换。
- 辩论、来源、TTS 和 Maya 报告以英文为权威原文。
- 教师可以按键翻译当前已公开内容为中文供测试。
- 译文不进入 RAG、后续辩论、TTS 或 Maya 输入。
- Demo 学生端和匿名端不提供课堂译文入口。

## 10. 明确不做

- PDF/TXT/OCR、知识正文在线编辑；
- 课程/小组写操作、SSO、多教师管理页面；
- 第 3-5 轮、主持/裁判、评分/Evaluation；
- 观众登录、防重、反作弊、压力测试、内容审核；
- 精细 3D/身体/高精度口型/Maya 数字人；
- 音频下载、全部历史音频长期保存；
- 云部署、GitHub Pages 运行后端、生产级限流/备份/合规；
- 直接复制粘贴任何参考仓库实现代码、整段改名或继承其领域模型。

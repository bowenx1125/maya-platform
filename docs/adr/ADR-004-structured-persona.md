# ADR-004: Extraction-only structured Persona

Status: `ACCEPTED / NOT IMPLEMENTED`

Raw student `AGENT.md` remains immutable authorship and the audit/download source. New
AgentVersions also store a structured Persona extracted without invention, improvement
or silent omission. A current group member previews and confirms it before publication.
Legacy versions remain readable with no Persona backfill.

The closed schema, compiler behavior, unrecognized-content handling, revision/CAS and
Mock acceptance are frozen in
[`../contracts/DEBATE_GENERATION_CONTRACTS.md`](../contracts/DEBATE_GENERATION_CONTRACTS.md#persona).

# ADR-008: 单人 Agent 对话、课堂 Live 与 Provider 控制

Status: PROPOSED — 新功能待产品方案确认；复用与自研的技术边界由实现者判断。

## 目标与边界

把需求合并为三项：老师/学生与一个已有 Agent 进行文字、语音、3D 对话；
老师在网页管理五个能力的 Real/Mock 与 Check；学生观看老师 Immerse 的同步内容。
操作台按钮填满已有区域属于独立布局修复，不等待这些新功能上线。
不增加屏幕投射，不替换现有账号、Agent 发布、RAG、课堂状态机或费用记录系统。

“五个模型”在当前代码中实际是五个能力：Debate LLM、Embedding、Maya Report、
TTS、Voice。Voice 是声音克隆，不是语音识别；语音输入需要新增 ASR 能力。

## 1. 单人对话：共用页面，两种身份入口

老师、学生导航各增加 Chat。先选择已发布 Agent，再进入单人 3D + 消息列表 + 输入区。
建议首版可选择本课程全部已发布 Agent；跨课程、草稿和别人的私有声音不可用。
这个可见范围是方案建议，不扩大现有权限，须经产品确认后实现。

- 会话绑定用户、课程、不可变 AgentVersion 和 KnowledgeSnapshot；发布新版不会
  悄悄改变旧会话。换 Agent 开新会话，自己的历史可恢复，默认不让其他学生或老师
  自动读取个人会话内容。
- 复用 Persona、自己的知识检索、来源查看与平台 LLM 适配器；另建 chat session/
  message 存储和请求额度，不伪装成 Debate，也不回写 Agent.md。
- 当前 `/agent-versions/{version_id}/chat` 是草稿检索测试，不是完整多轮角色对话；
  不能直接把它作为成品。当前 published-agents 列表仅限老师，也要补学生受限投影。
- assistant-ui 只管理消息呈现、输入与交互；Maya 服务器是权限、历史、引用及费用的
  权威。关闭未接入的重试、编辑分叉、工具执行等入口，网络错误不偷偷再调用模型。
  保留现有安全 Markdown 渲染，不执行模型返回的 HTML。
- 语音首版采用“点击开始录音 → 停止 → 转写 → 可编辑文字 → 发送”。回答可朗读，
  也可停止/重播；3D 人物只跟随当前实际播放音频。文字功能在拒绝麦克风、ASR/TTS
  失败时仍可用。不默认常开麦克风，不承诺首版全双工打断对话。

语音链路：录音 → ASR → Maya 单人对话/RAG → TTS → 已有 3D 音频联动。
ASR 优先接供应商官方接口/SDK，不自行训练识别模型。官方
[语音识别说明](https://help.aliyun.com/zh/model-studio/asr-model)区分录音转写和实时流；
初版只需录音转写。浏览器录音需 HTTPS（localhost 例外）；学生通过局域网 HTTP IP
访问时必须解决安全上下文，不能只在老师 localhost 测试后宣称学生麦克风可用。
录音上传限制类型、大小与时长；拒绝权限时解释原因；结束录音即停止麦克风轨道，
原录音默认只做短期转写、不用于克隆声音，保留策略要明确。

## 2. 五能力开关、Check 与 Refresh

由老师管理；学生只读状态，不能看或改 API key。界面区分“选择 Real”和“已验证可用”，
不把保存成功当连接成功。缺 key 弹窗填写；提交后服务器只返回配置是否存在和检查状态，
不回传 key，不放 localStorage，不进入日志。持久密钥由服务器加密保存，主密钥不与
密文同库存储；不通过网页直接改 `.env`，也不默认给网页任意 URL 的 Provider 代理。

- **Refresh**：只读配置与最近结果，不发送模型请求，不收费。
- **Check**：先检查配置、策略和适配器；若要真实调用则明确展示检测类型与费用边界，
  经老师确认后用固定公开测试输入、独立小额度和幂等键执行一次，记录耗时、安全错误码
  与检测时间。超时结果不明时不自动重试。
- 检查与配置修订号绑定；改 key/模式后旧绿色状态失效。五项逐项独立展示，不能一个
  LLM 返回成功就声称 Voice、TTS、Embedding、Report 全部可用。
- Voice Check 查询已有授权声音状态，不每次新建克隆；“创建克隆”和“试听合成”
  是独立、可计费、需授权的操作。无声音时显示未准备，不制造成功状态。
- Real/Mock 切换作用于新任务；已运行任务冻结原配置，旧发言/报告/音频显示其原始
  来源。尤其不能用新 Embedding 空间查询旧向量；切换后不兼容快照必须重建或明确
  暂不可用，不能静默混用。
- 本地 Demo 建议配置持久化后可热切换，不要求每次重启 Docker；实现要处理并发
  修改和长任务的一致性，不只给静态 Composition 卡片加五个开关。

## 3. 为什么 TTS/Voice 仍是 Mock

审查时运行中的 LLM/Embedding/Report 为真实适配器，TTS/Voice 为 Mock。
以下是代码限制，不只是少填一个 key：

1. `backend/app/core/config.py` 明确拒绝运行时 Real Voice；允许的多真实组合没有
   TTS + LLM + Embedding + Report。
2. `backend/app/modules/demo_baseline/composition.py` 把 TTS 和 Voice 显示写死为
   Mock，未来必须改为服务器真实配置/检测投影，不能只改标签。
3. `backend/app/providers/factory.py` 和 `dashscope.py` 已有真实 TTS/克隆适配器，
   应复用，但仍需校验当前供应商接口、响应、声音授权、策略和计费规则。TTS 方法的
   language 参数目前没有发给供应商，中文/英文质量需要实测，不能仅凭方法签名认定支持。

建议先打通真实 TTS，使用允许的系统音色或完成准备/试听确认的默认声音；
后者若依赖克隆，要按现有分阶段流程办理，不能凭空使用 Mock voice id。
再接个人授权声音克隆，保持上传者所有权；“可选择某个 Agent”不等于“可用作者私有声音”。
最后接 ASR。扩大组合时同时补政策、成本上限、DTO、测试与故障处理，不移除安全门禁。
旧 Mock WAV 不会随配置变成真语音，只有对指定内容重新合成后才能验收为真实。

## 4. 学生 Live：共享课堂状态，不共享老师屏幕

直接扩展 `backend/app/modules/debates/playback/` 已有快照与有序事件，以及当前 Three.js
舞台；不新增媒体服务器。现有事件路由按老师授权，不能直接让学生使用控制员连接。

- 老师成功进入 Immerse 并持有有效控制权时，显式建立 Live 会话；不是链接预取或 GET
  请求就开直播。同课程学生的 Live 按钮亮起，并有文字状态，不只依赖颜色。
- 学生连接独立只读订阅，获得参与者、已公开发言、当前轮次、音频资源和播放游标。
  老师 Next/暂停/结束同步；不暴露私有教师备注、未发布内容、控制 token 或供应商 URL。
- 同一条音频由各设备播放，时间戳/游标校正误差；目标是相同内容和近实时进度，不承诺
  像素级画面一致。学生首次点击 Live 处理音频播放授权，拒绝/失败仍能看文字。
- 中途加入和手动重连先收当前快照，再按 sequence 消费事件，忽略旧消息；遵循现有
  手动重连约定，不为学生另造不兼容的自动恢复语义。
- 老师退出/End 关闭直播；断网或关页面由服务端租约到期关灯；控制权转移要有会话版本，
  防止旧老师页面重新发布。学生永远不能推进课堂。
- Live 只播放已生成内容，不给每个学生重复调用模型或 TTS；媒体 ticket 必须为该学生、
  课程、Live 会话签发，与老师播放控制票据分开。

## 顺序与验收

建议先确认这份产品边界，再按“文字单聊 → 真实 TTS/录音转写/单人 3D → 五能力网页
控制 → 学生 Live”实施；底层配置快照和权限结构可提前作为共用基础。
不以开源 Demo 能启动代替 Maya 集成验收。

| 功能          | 必须证明                                                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 单聊          | 老师/学生都能选授权 Agent、多轮对话、刷新恢复；跨用户/课程访问被拒绝；引用归属正确；不调用第三方聊天托管服务。                          |
| 语音/3D       | 中英文真实转写和朗读；麦克风拒绝、TTS 失败仍可文字交流；重复点击不重复计费；停止音频立即停止嘴部动画；学生 HTTPS 实机测试。             |
| Provider 控制 | 缺 key、错误 key、额度不足、检查过期、配置竞争均有可解释状态；刷新零调用；每项真实检测有独立记录；切换不污染旧产物。                    |
| Live          | 两个身份同时在线；入场、Next、中途加入、断线手动恢复、老师退出/租约过期均同步；学生无法发控制命令或读未公开内容；多学生不增加生成调用。 |

正式引入 assistant-ui 前以 [Custom Runtime 文档](https://www.assistant-ui.com/docs/runtimes/custom/overview)
和上表固定源码为依据完成小范围接入试验；不预先承诺必须使用该包。
全双工通话、精确音素口型、新的人物资产、多供应商网关与课堂规模压测不算首版已交付。

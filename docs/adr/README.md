# Architecture Decision Records

ADRs record durable decisions, not execution history. Status is one of `PROPOSED`,
`ACCEPTED`, `SUPERSEDED` or `REJECTED`.

- [ADR-001](ADR-001-immutable-agent-version.md): immutable AgentVersion.
- [ADR-002](ADR-002-knowledge-snapshot.md): immutable KnowledgeSnapshot.
- [ADR-003](ADR-003-manual-reconnect.md): manual-only network reconnect.
- [ADR-004](ADR-004-structured-persona.md): extraction-only structured Persona.
- [ADR-005](ADR-005-claim-evidence-trace.md): claim-level evidence provenance.
- [ADR-006](ADR-006-complete-history-prompt.md): complete predecessor transcript and
  duplicate-free request assembly.

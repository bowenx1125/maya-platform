# 墨子辩论基准包

这是团队内部的辩论基准。后来的改稿要超过它，才替换这份基准。平台不宣布胜者；对照在同一辩题、同一份中文 Ruleset、同一组对手下人工核对。

只上传下面两个文件。不要把本说明传进 RAG，否则对照表会被检索进发言。

| 文件                | 放进哪里        |
| ------------------- | --------------- |
| `mozi.agent.md`     | AGENT.md        |
| `mozi.knowledge.md` | 该 Agent 的 RAG |

## 装进平台

1. 在 Studyform 新建 Agent，名称写「墨子」。
2. AGENT.md 一栏点上传，选择 `mozi.agent.md`。上传会替换编辑器里的全文。
3. 同一页 Brainform 里点「上传 RAG」，选择 `mozi.knowledge.md`。
4. 点 Done。新建 Agent 时，Done 会创建并发布。
5. 开一场中文辩论，选这个已发布的墨子。系统里的苏格拉底、柏拉图、老子仍是原来的三份，这份不替换它们。

发言语言、轮次和证据类别由当场冻结的 Ruleset 决定。现行中文指导篇幅是前三轮 50 字、第四轮 100 字，服务器不按字数拒收。要比谁论证更完整，先在同一份 Ruleset 上比，不要只把字数上限改大。

## 基准已经会做的事

这些是底线。优化稿丢了任何一条，就不算超过基准。

| 轮次   | 基准行为                                                                                             |
| ------ | ---------------------------------------------------------------------------------------------------- |
| 第一轮 | 先用资料里的一句原话回答辩题，再给一个适用边界                                                       |
| 第二轮 | 点名程序指定对象的一个具体句子，并问一个对方还没回答的条件                                           |
| 第三轮 | 先回答实际收到的问题；没有问题就回应一项具体质疑                                                     |
| 第四轮 | 点名另一位的一个观点，说明保留、加了条件，还是修改                                                   |
| 每一轮 | 资料直接撑住才说「RAG证实」；只是背景就说「RAG提示」；资料没有的部分说「我感觉」，并指出是哪一条价值 |

证据分只表示支持类别：direct 为 5，contextual 为 2，no_match 为 0。它不表示事实为真。来源编号不读进正文。不编造资料未收录的章句、数字和史事。

## 怎样才算超过基准

同一辩题、同一中文 Ruleset、同一组对手，优化稿要同时满足：

1. 上表五条底线一条不丢。
2. 知识库新增至少一条本基准没有的《墨子》原句，并写明篇章。现代转述不能冒充原句。
3. 这条新原句在发言里被用到，而且摘录直接支撑那句主张。
4. 发言里至少有一处比基准更窄的适用边界，不能只写在 Agent.md 里。
5. 不把「本资料未收录」里的项目编造成事实。明鬼、非乐、节葬、完整墨经、现代统计和兵法尺寸，要么继续标明未收录，要么用对应原句补上。

五项都做到，才用优化稿替换本目录，并在替换说明里写下新原句的篇章。

## A. 一秒识别当前发言者

在 A1、B1、A2、B2 切换时分别检查：

- [ ] 5m 处能在 1 秒内指出谁正在发言；
- [ ] 8m 处仍能依靠高亮和动作判断，不依赖 speaking/listening 文字；
- [ ] 发言者高亮与实际音频开始同步；
- [ ] 非发言者呈现明显的 listening + attentive 状态；
- [ ] 切换时没有上一位仍保持 speaking 的残留；
- [ ] 暂停后角色状态不会误导观众；
- [ ] 停止后所有说话动作立即结束。

通过标准：四个回合全部正确，任何一次认错当前发言者都算失败。

## B. 正文与证据可读性

让一名未参与开发的人坐在 5m 和 8m 位置：

- [ ] 能在 5 秒内读完当前发言的任意一句；
- [ ] 不眯眼、不前倾、不要求放大浏览器；
- [ ] 能读清 Bowen 的来源文件名 `bowen-tiktok-evidence.md`；
- [ ] 能看出 KaiKai 是“无匹配证据/一般推理”；
- [ ] 正文每行长度适中，不因右侧历史区域导致正文过窄；
- [ ] 讲台操作区不会抢过正文和当前角色的视觉焦点。

通过标准：5m 全部通过；8m 至少能看清当前发言人、正文核心句和“有证据/无证据”状态。

- [ ] B2 的最后问题清楚指向全班；
- [ ] 四段总时长适合作为课堂环节。

## D. 教师按钮直觉性

请一名没看过说明的人操作，只告诉他“主持这场辩论”：

- [ ] 他能找到 Start 并理解点击一次后自动连续播放；
- [ ] 他能区分 Pause 与 Stop；
- [ ] 他知道 Skip 只跳过当前剩余播放；
- [ ] 他能找到 Resume；
- [ ] 他能找到 Replay all；
- [ ] 他能在历史中找到 Replay turn；
- [ ] 禁用按钮能让人理解当前为什么不可用；
- [ ] 操作后 1 秒内能看到状态反馈。

通过标准：不看说明，Start/Pause/Resume/Stop 全部一次成功；Skip/Replay 最多允许一次口头提示。

## E. RAG 教学效果

固定问题：

> Should the United States ban TikTok's recommendation algorithm?

- [ ] Bowen 显示 `matched`；
- [ ] Bowen 显示 `bowen-tiktok-evidence.md`；
- [ ] Bowen 发言包含与控制、推荐系统或 divestiture 有关的证据语义；
- [ ] KaiKai 显示 `no_match`；
- [ ] KaiKai 来源为空；
- [ ] KaiKai 没有虚构研究、数字、机构或文件；
- [ ] 一名普通观众可以用自己的话解释：“Bowen 的论点有知识文件支撑，KaiKai 这一段只是一般推理。”

最后一项是最重要的教学通过标准。状态标签正确但观众看不出差异，仍然算失败。
